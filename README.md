# Login e Cadastro

Interface demonstrativa criada com HTML, CSS e JavaScript.

## Arquivos
- `index.html`: estrutura da interface.
- `form.css`: estilos e responsividade.
- `form.js`: alternância entre login/cadastro e validação dos campos.

## Importante
Este projeto é apenas uma demonstração de interface. Ele não possui autenticação real,
não envia dados para um servidor e não armazena senhas.
